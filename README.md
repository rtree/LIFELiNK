# LIFELiNK

> You are never alone.

緊急時に事前登録済みの電話番号に電話するアプリ。

## ゴール

- 今回のこのアプリで狙うのは、声を出せない状況下でボタンを押すと、事前に指定した通話先に電話をかけ、その電話先に現在位置や状況を伝えるアプリ。
- ボタンは BLE の Beacon を使う。あらかじめリンクしておいた Beacon を使うということ。
- 電話先に伝える際に、電話をかけたときではなく、周辺の知識を集められる限り集めて伝えることがやりたい。

### 周辺の知識

- 位置情報
- 位置情報から割り出した住所
- マイクを ON にできたら、マイクの周辺音声の伝達。AI の音声に重ねて流せるのがベスト。
- 事前にリンクした友達のアプリウィンドウにもメンションが入り、その友達が返事した内容が通話先にも伝えられる。

通話先との会話内容・周辺知識は、アプリの会話履歴欄にも Discord 類似の会話チャンネルのような形式で表示される。また、友達のアプリにも表示されるようにしたい。

なお、これは緊急通知として全部盛りなので、World ID の IDKit で人間だと証明されていない人は使えないものとする。

そのための UI や画面遷移案も準備したい。Discord 類似で、以下の画面が必要。

- World ID を IDKit で証明する画面（Android ネイティブが無理なら、内蔵ブラウザを呼ぶ形式でもよい）
- 緊急連絡先の電話番号を登録する画面
- 友達を登録する画面
- 自分や友達の緊急通話履歴を見る画面

## ストレッチゴール

- ボタンを Beacon ではなく GATT にして、ロックしていても反応できるボタンを作る。
- 友達登録を Discord にして、友達として参加するときにアプリのインストールを不要にする。
